# 阿里云容器镜像部署说明

## 概述

本文档介绍如何使用阿里云容器镜像服务部署芋道系统，包括后端服务、前端服务、MySQL 和 Redis。

## 前提条件

- 已购买阿里云容器镜像服务实例
- 已将芋道系统的前后端服务打包并推送至阿里云镜像仓库
- 已安装 Docker 和 Docker Compose

## 镜像准备

以下镜像需要提前推送到阿里云镜像仓库：

- 后端服务镜像: `registry.cn-beijing.aliyuncs.com/[命名空间]/ruoyi-vue-pro:[版本号]`
- 前端服务镜像: `registry.cn-beijing.aliyuncs.com/[命名空间]/yudao-ui-admin-vue3:[版本号]`
- MySQL: `mysql:8.0`
- Redis: `redis:7-alpine`

## 部署步骤

### 1. 创建部署目录

```bash
mkdir -p /opt/yudao/yudao-deployment
cd /opt/yudao/yudao-deployment
```

### 2. 配置文件

将 `docker-compose.yml`、`nginx.conf` 和 `deploy.sh` 文件复制到部署目录中。
```bash
# 项目根目录 在这里下执行 deploy.sh 脚本中的 copy 命令，会自动创建部署目录并拷贝相关文件到部署目录
cd /root/workspaces/yudao/Single/ruoyi-vue-pro/ruoyi-vue-pro/script/shell
./deploy.sh copy

```

### 3. 配置环境变量

创建 `.env` 文件，配置数据库和镜像信息：

```bash
# MySQL 配置
MYSQL_ROOT_PASSWORD=123456
MYSQL_DATABASE=ruoyi-vue-pro
MYSQL_USER=root

# Redis 配置
REDIS_PASSWORD=

# 镜像配置
BACKEND_IMAGE=registry.cn-beijing.aliyuncs.com/[命名空间]/ruoyi-vue-pro:[版本号]
FRONTEND_IMAGE=registry.cn-beijing.aliyuncs.com/[命名空间]/yudao-ui-admin-vue3:[版本号]

# Java 应用配置
JAVA_OPTS="-Xms512m -Xmx1024m"
```

### 4. 设置权限

```bash
chmod +x deploy.sh
```

### 5. 部署服务

运行以下命令部署服务：

```bash
# 设置目录结构和权限
./deploy.sh setup

# 拉取最新镜像并启动服务
./deploy.sh build
```

### 6. 验证部署

```bash
# 查看服务状态
./deploy.sh status

# 查看服务日志
./deploy.sh logs
```

## 部署脚本使用说明

部署脚本支持以下命令：

- `./deploy.sh setup` - 设置目录结构和权限
- `./deploy.sh pull` - 拉取最新镜像
- `./deploy.sh build` - 拉取镜像并启动服务
- `./deploy.sh start` - 启动已部署的服务
- `./deploy.sh stop` - 停止所有服务
- `./deploy.sh restart` - 重启所有服务
- `./deploy.sh logs` - 查看服务日志
- `./deploy.sh status` - 查看服务状态
- `./deploy.sh cleanup` - 清理所有容器和数据
- `./deploy.sh help` - 显示帮助信息

## 环境配置

### 数据库初始化

首次部署时，系统会自动初始化数据库。SQL 文件应放在 `./sql/mysql/ruoyi-vue-pro.sql`。

### Nginx 配置

前端服务使用 Nginx 作为反向代理，配置文件为 `nginx.conf`，主要功能包括：
- 静态资源服务
- API 请求代理到后端服务
- URL 重写和路由

### 网络配置

- 前端访问地址: `http://<服务器IP>`
- 后端 API 地址: `http://<服务器IP>:48080`

### 数据持久化

- MySQL 数据存储在 `mysql_data` 卷中
- Redis 数据存储在 `redis_data` 卷中
- 应用日志存储在 `/var/log/yudao/ruoyi-vue-pro` 目录中

## 故障排查

### 服务启动失败

1. 检查 Docker 和 Docker Compose 是否正常安装
2. 查看服务日志：`./deploy.sh logs`
3. 确认镜像名称和标签是否正确

### 数据库连接问题

1. 检查 MySQL 容器是否正在运行
2. 确认环境变量中的数据库配置是否正确
3. 检查 MySQL 容器的日志

### Redis 连接问题

1. 检查 Redis 容器是否正在运行
2. 确认环境变量中的 Redis 配置是否正确

### 前端无法访问后端 API

1. 检查 Nginx 配置是否正确代理 API 请求
2. 确认前端容器中 nginx.conf 文件是否正确挂载
3. 检查后端服务是否正常运行

## 版本更新

要更新到新版本：

1. 更新 `.env` 文件中的镜像版本号
2. 运行 `./deploy.sh pull` 拉取新镜像
3. 运行 `./deploy.sh restart` 重启服务

## 注意事项

- 生产环境中请使用强密码替换默认密码
- 定期备份数据库和重要数据
- 根据服务器资源调整 Java 内存参数
- 确保防火墙开放相应端口（80, 48080, 3307, 6380）
